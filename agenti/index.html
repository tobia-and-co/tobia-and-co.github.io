Model Context Protocol (MCP)

🔌 Tobia dentro il tuo assistente AI

Usi Claude o un altro assistente AI? Collegalo a Tobia e potrai chiedergli «dove conviene fare benzina vicino a me?» o «quanto mi spetta per il volo cancellato?»: risponderà con i dati ufficiali di oggi.

🧰 Cosa impara il tuo assistente

⛽ CarburanteI distributori più convenienti vicino a un comune, contando prezzo e viaggio; i prezzi medi di oggi in Italia e per regione.
💊 FarmaciGli equivalenti che costano meno, dalla lista ufficiale AIFA.
✈️ VoliLa compensazione per ritardo, cancellazione o overbooking (Regolamento UE 261/2004).
🚆 TreniL'indennità per i ritardi (Regolamento UE 2021/782).
💱 CambiI cambi ufficiali della BCE di oggi.

🔗 Link già compilati

Non serve installare niente: il tuo assistente può darti un link che apre lo strumento già compilato e calcolato. Tutto avviene sul tuo telefono, nessun dato viene inviato.

✈️ Volo in ritardo/voli/?da=FCO&a=JFK&ritardo=4
Aeroporti con il codice a tre lettere. In più: evento=ritardo|cancellato|negato, causa=tecnico|sciopero|meteo|atc|sicurezza.
⛽ Carburante/carburante/?q=Frascati&carb=benzina
Un indirizzo o un comune; carburante: benzina|gasolio|gpl|metano.
🚆 Treno in ritardo/treno/?prezzo=59,90&ritardo=75&op=freccia
Prezzo del biglietto e minuti di ritardo; op=freccia|ic|reg|italo|altro.
🚓 Multa/multe/?importo=42&notifica=2026-11-03&infrazione=2026-07-20&spese=14,50
Date nel formato anno-mese-giorno; infrazione e spese sono facoltative.

⚙️ Come si collega (1 minuto)

Claude Code

claude mcp add tobia -- npx -y github:tobia-and-co/tobia-mcp

Claude Desktop, Cursor e altri client MCP

Aggiungi questo nella configurazione dei server MCP (serve Node.js 18 o più recente):

{ "mcpServers": { "tobia": { "command": "npx", "args": ["-y", "github:tobia-and-co/tobia-mcp"] } } }

Codice aperto (licenza MIT): github.com/tobia-and-co/tobia-mcp. Gratis e senza chiavi. Il server legge solo i dati pubblici di questo sito; quello che chiedi al tuo assistente non arriva a Tobia.

📦 Preferisci i dati grezzi?

Sono pubblici, in JSON, aggiornati in automatico: prezzi medi carburanti · storico giornaliero · farmaci equivalenti AIFA · cambi BCE · llms.txt.

Il calcolo dei rimborsi dei voli include un link di affiliazione AirHelp, sempre dichiarato: AirHelp trattiene una percentuale solo se vince, e si può sempre chiedere da soli gratis.
